APA ITU FOODIE?

Lebih mudah menemukan ide masakan.

Foodie adalah aplikasi pencarian resep makanan berbasis web. Pengguna dapat mencari hidangan, melihat bahan dan cara memasak, serta menyimpan resep favorit untuk dicoba kembali.

Proyek ini dibuat menggunakan Python, Flask, HTML, CSS, JavaScript, dan TheMealDB API sebagai sumber data resep.
